# Prototype

A small beginner-friendly website for practicing and combining HTML, CSS, and JavaScript.

## About

This project is a personal learning playground where I can experiment with page structure, responsive layouts, styling, and browser interactions. It does not need to be a finished product—the goal is to make, test, break, and improve useful small features one at a time.

## What I am practicing

- Semantic HTML
- CSS layout with Flexbox and Grid
- Responsive design and media queries
- Reusable classes and basic design patterns
- DOM selection and event handling
- JavaScript functions and simple state management
- Form validation and accessibility basics
- Debugging with browser developer tools

## Ideas to try

- Build a simple navigation bar
- Create a responsive card layout
- Add a light/dark theme toggle
- Make a mobile-friendly menu
- Add and remove items from a list
- Validate a contact or sign-up form
- Build a small calculator or tip calculator
- Add an image gallery or modal

## Running locally

1. Clone or download this repository.
2. Open `index.html` in a browser.
3. Or use a local server, such as the VS Code **Live Server** extension.

## Notes

This is a learning project, so it may change often. Clean, readable code is more important than perfection, and each improvement is another step toward stronger front-end fundamentals.
